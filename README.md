This is a django backend project(Online academy platform). In this project I create API's for Authentication, Course, Cart and Student. For authentication I implemented JWT auth, active account with email verification, reset password with email verification. For Order a course I implemented Paypal and stripe payment system.  

## 🗂️ Project Structure:
- `appApi`: In this folder all models and serializers for this project implemented.

- `appAuth`: In this folder all views and urls related to authentication has been implemented.


- `appCart`: In this folder all views and urls related to cart has been implemented.


- `appCourse`: In this folder all views and urls related to course has been implemented.


- `appStudent`: In this project all views and urls related to student has been implemented.
